## Native contract

Schema30 stores a separate bounded canonical `plugin_links` payload. It owns
display/raw metadata and exact provider, ABI/profile, semantic contract, module,
dependency and normalized explicit-option identity. Built-in reader/view/source
payloads and public `ReaderSource`/source association layouts are preserved.
The original72-byte ABI1 reader table is unchanged; an optional24-byte file-set
table observes primary and companion sources before decoder open.

Opening a project does not load or freeze the provider catalog. Cached metadata,
retained results and exact resave remain usable without a provider. Pixel access
requires the exact saved implementation and observed files. A changed module or
dependency requires explicit source adoption; matching pixels cannot authorize
the historical implementation identity. Saved options override new manifest
defaults. Existing native output guards protect source companions and aliases.

RegionAnalysis hashes the plugin implementation binding. Existing Tissue/Cell
pixel hashes stay unchanged, while their native verification refuses rebinding
historical archives to changed reader code. Recompute and retain a new result.
Raw metadata/sample forwarding does not admit new quantitative recipes.
