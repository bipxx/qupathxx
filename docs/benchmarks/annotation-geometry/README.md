# Native annotation geometry interoperability

The active qualified-catalogue goal adds the optional native
[pixel geometry TSV provider](../../../plugins/geometry_tsv/README.md),
annotation ABI2 and a source-matched native host/CLI. The existing QRO/Roi,
preview/apply, class mapping, image/source guards, publication, project and undo
authorities own application behavior. No new geometric kernel, Python fallback,
Java runtime, GUI, binding, wheel or public release is part of this packet.
