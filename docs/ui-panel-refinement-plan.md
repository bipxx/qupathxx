## 1. Image and shared input context

Image: use a compact identity summary, muted dimensions/pyramid details, a Display
heading with its reset action, and a Calibration heading with Edit. Replace the
three stacked inline calibration buttons with a registered Calibration editor:
Cancel, explicit Clear calibration, Apply calibration. Capture document, active image, workspace
epoch and calibration revision; stale owners cannot publish. Initialize a fresh
draft on open; native set/clear perform all validation. Closing never changes data.
Retain unknown calibration and per-axis values; units remain explicit.

Show saved image profile as saved, rather than implying it is active. Move full
saved stain vectors into an Analysis tab in the existing read-only Image information
view. Leave Use saved stains explicit and available without ROI in Region.

Region/Tissue/Cells show the actual active input context: feature/stain transform,
white reference and body/nucleus where applicable. Use read-only summaries from the existing make_transform task flag and cache them
on sampling_key; link Edit to Region through focus_task. Do not add another write
path or change vectors/white/complete basis. Only Region/Tissue show Body/Nucleus;
Cells ignores that flag. Compare current transform values to saved settings rather
than tracking a potentially stale origin label. Preserve make_transform exactly.
Remove nested Region advanced controls: model files and estimation settings get
separate single-level sections. Keep ROI policy and essential controls reachable.

## 2. Annotation inspection

edit retains existing native handler/replay targets. Property clearing/conversion

## 3. Tables and settings

destination and explicit export action. Keep the existing two destination drafts (Cells, shared ROI/Tissue), original
native job/request types, create-only/replace guards, existing shortcuts and scope
semantics. Cells/Image exposes saved run of selected annotation versus live objects. Route
its button and shortcut through one helper preserving the selected latest-run
behavior; never introduce an all-kept-runs route or a fallback. Test two kept runs
on one ROI. Retain counts and currentness
options; keep both independent jobs polling and their errors/cancel accessible
when switching table kind/task. Do not change API defaults or native exporters.

Project settings gets direct Metadata, Classes/defaults and Recovery categories;
remove the outer Project tools fold and duplicate density launcher. Keep recovery
controls/jobs available independently of settings visibility.

## 4. Specialist entry and staged actions

model ownership and native state machines. No new scientific workflow engine.
