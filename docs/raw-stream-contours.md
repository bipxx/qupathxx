## Decisive reference

[The synthetic reference](../tests/fixtures/raw-contour-seams-v1/reference.json)
is generated by [a standard-library-only oracle](../tools/reference_raw_contour_seams.py).
It enumerates labelled cell boundaries independently of native boundary-run
compression and GEOS. Exact rational areas/perimeters and hand-counted topology
cover four patterns:

| Pattern | Distinguishing outcome |
| --- | --- |
| Nested holes | Class 1 has 16 cells, perimeter 32 and one hole; class 2 has 8 cells, perimeter 16 and one hole |
| Diagonal contacts | Four isolated cells remain four polygon parts. Point contacts do not supply edges to cancel |
| Three-class junction | Counts 5/7/4 and perimeters 10/16/10 preserve every shared class boundary |
| Cropped anisotropic ring | Global first indices (3,3), steps (5/2,7/2) and world origin (17/2,25/2). Outer class area/perimeter 105/72, inner class 35/24 |

Each pattern uses 1x1, 2x3, 3x2 and 4x4 tiles. Cancelling opposite same-class
unit edges produces the exact global oracle in forward and reverse order.
Concatenating independently closed tiles invents seams in the connected
patterns; relocating the cropped window to local index zero changes geometry.
Area alone cannot expose replacing anisotropic steps with their geometric mean.

[Installed tests](../tests/test_raw_contour_seams.py) use actual float32 TIFFs
and a native three-class forest. Full prediction labels must equal the authored
pattern before tracing. Every native geometry edge, part, hole, pixel count,
area and perimeter is checked against the oracle. All 16 actual stream layouts
deliver each selected sample once with identical labels and global indices.
The full-grid oracle for the crop uses a small global grid and captured ROI;
it is not a whole-slide allocation strategy.

The cropped source halo must be finite where a sample footprint overlaps it.
Unit-grid unclassified cells instead contain NaNs throughout their footprint.
The initial fixture mixed these cases and correctly failed support admission;
retain that failure rather than weakening validity or expected labels. All
reference coordinates are integers or half-integers, so area/perimeter checks
require exact binary64 equality. No tolerance or scientific xfail changes.

This establishes synthetic geometry and existing-producer behavior only. It
does not establish biological equivalence, native streaming contours, bounded
whole-slide memory, platform support or apply authority.

The [local receipt](benchmarks/raw-contour-seams-local.json) binds the reference
test source, prior installed `0dc916c` runtime and exact wheel member separately.
All ten new cases and 91 affected regressions pass; two OpenSlide cases skip.
Initial fixture failures remain captured. No native rebuild was needed.

## Smallest native path

1. Reuse `RawPixelTiledPredictionRequest` and `RawPixelPredictionStream`. Extract
   boundary runs within each owning block, retaining the global integer sample
   indices and adjacent class labels. Reconcile shared block borders before
   polygonization. Do not retain completed raster blocks or concatenate masks.
2. Reuse the existing GEOS polygonization, clipping and geometry extraction in
   `tissue_contours.cpp`. The streamed adapter now uses tagged-edge batch lookup;
   existing full-grid consumers retain their raster lookup. Preserve the exact
   geometry oracle and both global axes while delivering the captured result.
   Avoid one full boundary scan per face or any full-mask allocation.
3. Keep both lattice axes when mapping integer vertices to world coordinates.
   Admit boundary storage, polygonization, retained geometry and output IDs
   against explicit limits. Cancel between blocks and inside GEOS; release each
   prediction block before advancing. Do not call an edge budget process RSS.
4. Return a distinct immutable stream-contour result. Existing `RawPixelContours`
   owns a full prediction and must not be populated with a fabricated raster.
   Bind the new result thinly, reusing native jobs and the shared frontend.
5. Publish only through a fresh owner-bound request and one atomic document edit,
   reserving the complete result and anticipated IDs before mutation. Reuse
   current stale/model/image/source checks, cancellation and undo/redo. QWS1
   historical blocks may support historical geometry; verified current request
   inputs are still required for live apply.

Before accepting the workflow, add incomplete/overlapping block refusal,
edge/work/output limits, source/model mutation and cancellation controls, then

cohorts into the existing producer/auditor closure after interfaces settle.
Keep the current T5 candidate frozen; do not run another broad platform campaign
